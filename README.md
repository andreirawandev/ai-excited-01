"I DREW THIS — NO PROMPT. JUST CODE." A small robot rides a giant pencil like a rocket across a blazing sunset sky, the pencil tip touching the sun and drawing its own rainbow comet trail behind it. The image is drawn entirely in code: a hand-written rasterizer in Node 22 (standard library only) paints the gradient sky, stars, comet trail, pencil, robot, and bold pixel text, and encodes the PNG by hand with zlib. No image model, no prompt, no asset — the twist is the point: an AI agent drew this, pixel by pixel.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
